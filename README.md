# Evidence Log (Verifiable Proof of Impact)

**Repo purpose:** a public, timestamped evidence vault for my **mentorship**, **talks**, **media/publications**, **community impact**, and **innovation delivery** — using links + proof that can be independently verified. :contentReference[oaicite:1]{index=1}

## What you’ll find here

This repository is organised as a growing archive of:

- ✅ Mentorship sessions + outcomes (what was taught, improvement, reflections)
- ✅ Innovation build logs (new features, prototypes, experiments, iterations)
- ✅ Media & publications (articles, interviews, university/blog features, etc.)
- ✅ Supporting assets (photos/videos/screenshots used as proof)

## Evidence standards (how I keep this verifiable)

Each evidence item aims to include:

1. **Date + context**
2. **What happened** (activity summary)
3. **My role** (what I personally did)
4. **Outcome/impact** (measurable or observable result)
5. **Proof links** (public URLs where possible)
6. **Artifacts** (screenshots, video clips, documents)

## How to add new evidence (workflow)

1. Create a dated folder or file:
   - `Innovation Log/YYYY-MM-DD/`
   - or add a new row/file inside `mentorship-tracker/`

2. Add a short markdown write-up:
   - `README.md` in the dated folder, or
   - `session-XX.md` inside `mentorship-tracker/`

3. Attach proof assets:
   - images (`.jpg/.png`)
   - short clips (`.mp4`)
   - links to external proof (YouTube, blog post, LinkedIn post, event page)

4. Commit with a clear message, e.g.:
   - `Add mentorship evidence - 2025-12-14`
   - `Log innovation update - chassis design concept`
